# Thiruwin Karthik Portfolio

A modern developer portfolio built with React, Vite, and Tailwind-compatible design tokens.

## Live Portfolio

[Open the portfolio UI](https://thiuwinKarthik.github.io/portfolio/)

## Local Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

The site is deployed automatically to GitHub Pages whenever `main` is updated.
